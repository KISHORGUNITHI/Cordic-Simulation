Slide 02 / 14 • Introduction

The Hardware Trigonometry Dilemma

❌ The Challenge in Hardware

  • ALUs natively do add, subtract, and shift. They cannot directly evaluate transcendental functions like sin(θ) and cos(θ).
  • Taylor Series Expansion: Requires multiple 32-bit multipliers and dividers. Huge silicon area, variable latency, high power.
  • Direct ROM Lookups: 16-bit resolution table requires 256 KB of on-chip memory — prohibitively expensive for embedded applications.

✔ The Solution: CORDIC

  • COordinate Rotation DIgital Computer (Volder, 1959).
  • Decomposes rotation into micro-steps where tan(αi) = 2-i.
  • Zero multipliers needed: Multiplication by 2-i is just an arithmetic right shift (>>> i)!
  • Generates both sine and cosine simultaneously in fixed cycles.
Slide 03 / 14 • Mathematics

CORDIC Iteration Recurrence Equations

At each step i (from 0 to 15), the vector rotates by elementary angle αi chosen so &tan;αi = 2-i:

Xi+1 = Xi − σi • (Yi >>> i)
Yi+1 = Yi + σi • (Xi >>> i)
Zi+1 = Zi − σi • αi   where σi = (Zi ≥ 0) ? +1 : −1

Scaling Factor (K)

Micro-rotations expand vector magnitude by K16 ≈ 1.64676.

Multiplier-Free Compensation: We initialize X0 = 1/K ≈ 0.607253 (0x04DBA7 in Q3.19). Output is automatically scaled!

Angle Convergence (Z → 0)

Residual angle Z oscillates and rapidly converges to zero.

After 16 iterations: X ≈ cos(θ) and Y ≈ sin(θ) with residual error < 10-5 rad.

Slide 04 / 14 • Microarchitecture

Top-Level System Architecture

The processor is partitioned into 7 modular RTL blocks following clean Datapath vs Control Unit separation:

cordic_top (Top System)
 └── cordic_quadrant    ← Folds full-circle [-π, +π] into [0, +π/2] (Q1..Q4 reflection)
 └── cordic_fsm      ← 4-State Moore controller (IDLE → LOAD → ITERATE → DONE)
 └── cordic_iter_counter  ← 4-bit synchronous counter (0..15), asserts iter_done
 └── cordic_atan_rom    ← 16-word lookup ROM storing round(atan(2^-i) * 2^18)
 └── cordic_datapath    ← 22-bit shift-and-add arithmetic registers (X, Y, Z)
 └── cordic_output_reg   ← Rounding bias, quadrant sign restore, saturation, done pulse
Slide 05 / 14 • Control Subsystem

4-State Moore Finite State Machine

State Transition Flow

  • IDLE (00): Asserts ready = 1, cnt_rst = 1. Awaits single-cycle start = 1.
  • LOAD (01): Asserts load_en = 1. Initializes X0 = 1/K, Y0 = 0, Z0 = folded angle.
  • ITERATE (10): Asserts iter_en = 1. Datapath iterates while counter counts 0 to 15.
  • DONE (11): Asserts out_latch = 1. Latches outputs and emits single-cycle done = 1.

Slide 06 / 14 • Datapath Subsystem

Datapath & Arithmetic Right Shifters

The 22-bit arithmetic datapath executes parallel updates without any multiplication:

assign sigma  = z_reg[21];          // Sign bit: 0=CCW, 1=CW
assign x_shift = x_reg >>> iter_count;    // Arithmetic shift with sign replication
assign y_shift = y_reg >>> iter_count;

assign x_next  = sigma ? (x_reg + y_shift) : (x_reg - y_shift);
assign y_next  = sigma ? (y_reg - x_shift) : (y_reg + x_shift);
assign z_next  = sigma ? (z_reg + atan_ext) : (z_reg - atan_ext);

Why >>> (Arithmetic Shift) Matters in COA

Coordinates X, Y, Z are signed 2's complement numbers. Standard logical shift (>>) inserts zeros, destroying negative signs. Arithmetic right shift (>>>) replicates the sign bit (MSB), preserving mathematical 2's complement values!

Slide 08 / 14 • Full-Circle Extension

Quadrant Folding & Sign Reconstruction

CORDIC elementary angles sum to Σαi ≈ 99.88° (< 1.74 rad). It cannot naturally converge to ±180°. We solve this with symmetric reflection:

Input Quadrant Folding

  • Q1 [0, +π/2]: θ' = θ
  • Q2 (+π/2, +π]: θ' = π − θ
  • Q3 [-π, -π/2): θ' = θ + π
  • Q4 [-π/2, 0): θ' = −θ

Output Sign Restoration

  • Q1: cos = +X,  sin = +Y
  • Q2: cos = −X,  sin = +Y
  • Q3: cos = −X,  sin = −Y
  • Q4: cos = +X,  sin = −Y

• Busy Immunity: Spurious starts during ITERATE ignored.

Slide 11 / 14 • Academic Mapping

COA Concepts Directly Implemented

  • Shift-Add Arithmetic: Multiplier replacement via binary right shifting.
  • FSM Controller: 4-state Moore machine governing control flow.
  • Fixed-Point Systems: Signed Q3.13 and Q1.15 data representation.
  • Control/Datapath Split: Classic Harvard-style modular isolation.
  • Bus Handshaking: Synchronous start/ready/done handshakes.
  • Guard Bits: Integer overflow prevention & truncation control.
  • ROM Addressing: Counter outputs directly index the coefficient table.
  • Deterministic Latency: Fixed 18-cycle execution budgeting.
  • Saturation Arithmetic: Eliminates +1.0 2's complement wraparound.
  • Hardware Modularity: Hierarchical structural integration in Verilog.
